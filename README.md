# Siyahi

Siyahi (Hindi for ink) is a design language for data-heavy personal apps and reports,
shipped as `@siyahi/ui`: stock shadcn/ui on Tailwind v4 and Base UI, a small set of
finance compositions (delta, price chart, treemap, viewer time), formatters for Indian
numbers and IST, a lint that keeps pages on tokens, and a catalogue site that is the
style guide.

Built for [dash](https://github.com/jatinbansal1998/dash) and a transactions analyser,
and meant to be usable by anyone who wants the same look.

Design: `docs/superpowers/specs/2026-10-20-siyahi-design.md`.
