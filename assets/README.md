# Project icons

`icon.svg` is Siyahi's main mark. `t3-icon.svg` is the amber outline variant
for T3 Code's project icon. Its colour is explicit so it stays visible when
T3 Code's theme differs from the operating system's theme.

Select `t3-icon.svg` as the project's icon file in T3 Code. Use the file
picker rather than the built-in icon picker: the thread list can fall back
to the project's initials for a built-in icon.
